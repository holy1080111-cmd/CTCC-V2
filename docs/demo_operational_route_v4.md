# Demo operational route V4 (initial diagnostic only)

The V4 module first requires one native, signed, read-only Demo `GET /api/v5/account/config` on the route pinned by the current controlled credential session. It accepts an observation only after verified TLS to that exact host, a strict OKX success envelope, exact UID and main UID, supported account and position modes, synchronized host-clock evidence, causal request/response timestamps, bounded raw bytes, and unchanged session credentials. One monotonic deadline covers client enter, the GET, and the entire response body; response and client then receive separate one-second shielded closes. Slow-drip, cancellation, timeout, or failed cleanup cannot issue a lease. Redirects, proxies, retries, injected transports, cookies, changed settings, `50110`, and `50119` fail closed. The HTTP body remains in memory only until its one-use lease is consumed or the session is discarded; this is not durable source custody.

One session may start at most one V4 probe, even if it fails. The resulting route lease is bound to the same asyncio task and loop, process, thread, client, credential content, session binding, account UID/main UID, exact host, observation bytes, TLS peer, and timestamps. It expires after five seconds and is burned on the first consume attempt. Consumption returns only an initial-stage reviewed route declaration; the route-issuer module has **no public network sender** and cannot authorize a G12 continuation, portfolio snapshot, risk reservation, intent, or order.

The accepted signed GET can establish that this key and exact account were served on this **operational route for this invocation**. It cannot prove where the account was originally registered. Accordingly `registration_site=UNKNOWN`, `post_g12_eligible=false`, `public_source_authenticity_verified=false`, `account_complete=false`, `execution_authority=false`, and `admission=DENY` remain fixed. No V2/V3 public source or qualification path consumes this V4 lease; their existing hard DENY remains.

`demo_initial_public_source_v4.py` adds only the first initial-stage public step. In one task, it obtains the signed account/config observation above, consumes its lease, and then issues one unauthenticated Demo `GET /api/v5/public/time` to the same reviewed route. The request start must be strictly after account validation and lease consumption and within five seconds. The native HTTP pool must have verified TLS with no proxy, redirect, retry, UDS, local address, custom socket options, shared cookies, or injected transport. The time body is bounded, hashed, kept in memory, and checked against request/header/body/validation clocks. Cancellation closes both the response and client through bounded shielded cleanup. The result remains a `DENY` diagnostic with `durable_custody=false`; it does not capture OHLC, ticker, mark, funding, books, OI, or WS. A complete V4 collector still needs durable no-clobber raw publication/readback and a separate fresh account-route lease after an owned G12 publication barrier.

The public client entry and body share one five-second absolute monotonic deadline, rechecked immediately before sending. A hanging entry, slow-drip body, cancellation, or failed late close returns no observation and leaves the account lease spent. These failure cases and complete byte-preserving diagnostic replay are covered by offline tests.

No authenticated OKX request was executed as part of this offline implementation or its synthetic tests.
