# Demo operational route V4 (initial diagnostic only)

The V4 module first requires one native, signed, read-only Demo `GET /api/v5/account/config` on the route pinned by the current controlled credential session. It accepts an observation only after verified TLS to that exact host, a strict OKX success envelope, exact UID and main UID, supported account and position modes, synchronized host-clock evidence, causal request/response timestamps, bounded raw bytes, and unchanged session credentials. Redirects, proxies, retries, injected transports, cookies, changed settings, `50110`, and `50119` fail closed. The HTTP body remains in memory only until its one-use lease is consumed or the session is discarded; this is not durable source custody.

One session may start at most one V4 probe, even if it fails. The resulting route lease is bound to the same asyncio task and loop, process, thread, client, credential content, session binding, account UID/main UID, exact host, observation bytes, TLS peer, and timestamps. It expires after five seconds and is burned on the first consume attempt. Consumption returns only an initial-stage reviewed route declaration; the module has **no public network sender** and cannot authorize a G12 continuation, portfolio snapshot, risk reservation, intent, or order.

The accepted signed GET can establish that this key and exact account were served on this **operational route for this invocation**. It cannot prove where the account was originally registered. Accordingly `registration_site=UNKNOWN`, `post_g12_eligible=false`, `public_source_authenticity_verified=false`, `account_complete=false`, `execution_authority=false`, and `admission=DENY` remain fixed. No V2/V3 public source or qualification path consumes this V4 lease; their existing hard DENY remains. A future V4 collector must begin each public request only after consuming an owned route lease, retain and read back raw public bytes, and mint a separate fresh lease after an owned G12 publication barrier for post-G12 recheck. This implementation does not claim those later stages.

No authenticated OKX request was executed as part of this offline implementation or its synthetic tests.
