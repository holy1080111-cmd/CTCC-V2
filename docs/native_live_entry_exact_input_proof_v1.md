This private continuation preserves the existing initial G1–G11, six-file G12
publication/readback, new post-publication account/public capture, and full fixed
R7 computation. It never turns a saved report, receipt, DTO or `passed` flag into
an execution owner. Live remains default OFF and requires the existing current
human challenge and one-shot Arm.

`entry_owned_seal_v1` prepares a pending proof only from the original coordinator
run frame after its full R7 succeeds. It completes that proof only from that
same frame after the atomic reservation/intent call returns its independent
readback. Unknown commit/readback, WAIT, failure or cancellation retires the
pending proof. Existing durable reservations and event tombstones are untouched.

Each native gate independently:

- verifies the original owner, invocation, task, credential lease and source
  bindings;
- reopens all original account current, baseline and history attempts, including
  earlier immutable prefixes, with native private-directory/file checks and exact
  inventory/hash comparisons;
- reopens the old initial public bank as old evidence and the new post-G12 bank
  as current evidence; the latter reparses the original raw REST quote and WS
  reference under a newly measured clock;
- reads every G12 artifact and compares all actual model/input fields, fixed
  geometry, policy, financial operands, intent/readback, and mutable calculation
  constants; same-name foreign model classes are rejected;
- checks original code/namespace bindings, quote/account/risk freshness, original
  Arm/event/zone expiry, unchanged completed-bar cutoffs, UTC midnight and every
  known rolling-cash inclusion boundary. A boundary cancels this attempt rather
  than retiming its old calculation.

The two private public-byte readers work only inside an active synchronous
original proof replay. That scope has no await and closes in `finally`; it avoids
redundant nested coordinator scans within one gate. Every subsequent physical
gate performs its own complete replay. The physical boundary also samples the
final clock after the heavy replay and retains its existing held SQL
Control/catalog/reservation/intent/cap checks, native TLS and exact-wire checks.

The durable intent deadline is shortened to the original account observation's
freshness deadline (floored to datetime precision). Its original candidate,
entry, SL, TP, event and policy are unchanged. Neither the original Arm deadline
nor the account/quote five-second policy is extended.

The input serializer traverses the actual bounded model graph on every call. It
encodes a typed node/schema table with every edge, reference, multiplicity and
field path, then computes one final SHA256. Different objects are never merged
by equal content. Repeated references are charged their full expanded node,
byte and depth costs; cycles are rejected. Its memo exists only during
that synchronous traversal and retains no model hash or observation between
guards. It distinguishes unknown, zero, false, numeric types, decimal
representations, field/container types, ordered source rows and original source
classes. It does not invoke a model's saved receipt/dump as a substitute for its
actual fields.

The final recheck journal is DATA and explicitly records
`full_math_recomputed=false`, `original_exact_inputs_replayed=true` and
`execution_authority=false`. The committed R7/evidence/intent digests remain
immutable. Postsubmit and controlled exit retain their separate original
authority and consent boundaries.
