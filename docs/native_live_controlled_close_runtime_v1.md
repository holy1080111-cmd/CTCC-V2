# Owned controlled micro exit

Live remains default OFF. A saved receipt, constructor, API boolean or old Arm
cannot close a position. The original worker must consume the separately shown
and confirmed 120-second CLOSE permission. It allows one reduce-only FOK for the
original contracts, isolated/net mode, with the original SL as its adverse price
boundary. Its UTC and monotonic expiry never extend.

The required entry disarm is a separately committed/read-back negative action.
The close lineage accepts only its exact source-proven one-step Control revision
successor, same account/session/process/policy and no Arm. An earlier external
disarm, later revision, stop/clear cycle, uncertain readback, cancellation or
restart cannot be adopted. EStop revokes both close and original-algo cleanup;
this permission cannot clear it or perform an implied stop-aware liquidation.

The flow is new public source, new complete account/protection readback, fixed
original fill economics, signed close intent, independent readback, signed
one-shot action claim, independent readback, then the dedicated native TLS gate.
The account lock, legacy exposure fence, exact Control/reservation/intent/claim
and current source checks remain held through DNS/TLS/native writes. The order
has an exchange `expTime` derived only from that immutable action deadline.

An ACK is not flatness. Its exact numeric order ID must agree with fresh stable
order reads and a complete bill-ID fill chain. Entry/exit trade or bill conflicts
within the same instrument, partial fills, late orders, changed protection or
unknown data keep the reservation and durable claim. No second FOK is sent.

Cleanup may cancel only the exact original algo, after a newly replayed complete
account proves the close fully filled, positions and ordinary pending are zero,
and that original algo is the only remaining pending algo. Cleanup has its own
immutable action claim and new deadline, still within the original permission.
A final new complete account and exact canceled-algo readback are required before
the signed terminal proof can resolve the reservation. Response and raw journals
are retained on late rejection; no accepted file is removed to mask failure.

The exit-only quote replay reopens and hashes the entire original raw inventory,
plan, packet, receipt and native root identities on every call. It freshly
parses quote/mark/funding/WS bytes and samples a new clock. The original full
OHLC audit remains bound to unchanged bytes; this purpose returns no market
snapshot or entry qualification and caches no quote/model/clock/eligibility.
Default entry and full post-G12 replay retain their separate contracts.

The synthetic native-paced CPU rehearsal measured capture at 2.380 seconds and
ten inventory/quote/WS replays at 0.094 seconds; observed quote age was 2.421
seconds under the unchanged 5-second rule. This is a CPU budget measurement,
not venue, database, actual order or full production acceptance. Network latency
can still cause a correct fail-closed refusal.
