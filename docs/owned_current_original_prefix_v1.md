# Current-frame original base G1–G5 prefix V1

`consume_current_original_base_prefix_v1` accepts only an unused opaque
`OwnedCurrentOriginalFrameV1`. It moves the frame's existing registry ownership
before doing work. Ordinary operands, source bundles, stored receipts, caller
gates, policies, clocks and callbacks cannot enter this API. The old frame
capture/consume/close interfaces remain unchanged; consuming either path burns
the other path as well.

The private continuation independently replays the original V4 raw owners and
the fixed native G1/precursor. It runs the existing shared base route/HTF/setup
arithmetic and original trigger replay. The score 85, captured tick, drift
30 bps, spread 3 bps and adverse funding 5 bps assumptions are exactly the
existing V6 inspection semantics. This remains an **uncalibrated engineering
inspection**, not a registered trading policy. The four history strategies are
not mapped onto base strategy semantics.

Only five passing, ordered gates can produce the process-local prefix carrier.
An actual regime, HTF, required/veto/score, spread/funding or trigger failure
rejects that invocation. The owner retains actual typed result, trigger and
original zone lineage through immutable receipt hashes; it does not merely
forward a caller's PASS flag. `consume_owned_current_original_base_prefix_v1`
burns that owner first, independently replays the same raw originals, recomputes
the five gates and compares the entire receipt. Its returned typed operands are
ordinary DTOs and cannot reconstruct an owner. A later source coordinator must
consume the live owner within its controlled phase, never promote that DTO.

Original report, instrument, direction, entry, event, source timeline, prefix
witness, zone, creation time and expiry remain fixed. Trigger extraction here
replays the pinned original raw candles at their original creation time; it
does not search a later window. G6 is not evaluated with an invented empty
event set, and G7 is not passed merely because the precursor contains a zone.
No stop, target, quantity or leverage is selected or changed.

After arithmetic and at handoff, the same private frame rechecks task, loop,
process, thread, credential lease, controlled sessions, configured native
factory/engine pins, original retained raw bytes and both original source
freshness predicates at a later native stamp. No new source request, DB await,
deadline refresh or retry is introduced. A slow replay can exhaust the earlier
source's five-second current window and must reject. Actual completion within
that window remains **unmeasured**; synthetic provider clocks in the unit tests
do not establish native elapsed acceptance.

Cancellation, failure, expiry and close release the held local market claim and
leave native journals/raw custody/tombstones intact. A failed handoff stays
burned. Explicit close is idempotent. Like the original weak registry, this is a
process-local ownership boundary without a finalizer or restart recovery:
external traceback/task references can delay collection, and garbage collection
is not a guarantee of immediate resource release. Hostile mutation of shared
Python module/class/global code or a native engine remains outside this
application boundary.

The prefix has no complete consumed-event history, G6/G7, calibrated
protection/economics, complete portfolio/HWM/streak/funding/fees/local exposure,
source-earned account revision, G12, R7, reservation, intent or execution
authority. Those fields remain false. No default router, scheduler or submit
path is wired. Existing Demo/Live, durable ledger, dispatch and private-write
DENYs remain unchanged. Tests use declared synthetic native providers and real
V4/raw/G1/precursor/shared gate functions; they establish component behavior,
not TLS/PG/Demo, historical PIT, full G1–G12, OOS, Live or release acceptance.
