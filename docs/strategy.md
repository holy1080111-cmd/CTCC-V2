# Strategy Evaluation v0.5

This layer evaluates eight frozen strategy families without placing orders.

Each evaluator returns:

- completion ratio
- score components
- passed and failed conditions
- vetoes
- optional candidate with entry, stop, target and risk/reward
- causal multi-timeframe derivative confirmation with explicit confidence and
  aligned/opposed timeframe evidence
- direction-specific mathematical confirmation with high/medium/low/blocked
  grade, coverage, consensus, reliability, instability, validation labels,
  and a separately isolated auxiliary bonus

Safety boundaries:

- no broker imports
- no order submission
- no position sizing
- AUTO_TRADE remains false
- LIVE_TRADING remains false


Order-block evaluation uses a formal, conservative displacement-backed domain object generated by the structure engine.

The shared mathematical core vetoes an opposed or unstable candidate before
strategy selection. The adaptive Demo risk layer maps the remaining
mathematical grade to a downward-only effective-score cap. It cannot add
strategy points. Uncalibrated evidence may only break a tie after execution
score, raw score, and validated confidence are equal; the risk engine never
reads that auxiliary bonus. The isolated OKX Live boundary is unchanged.
