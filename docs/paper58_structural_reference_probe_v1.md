# Source58 structural reference validation

The fixed `--paper58-structural-reference` purpose creates two independent
fresh canonical0055 databases and applies the original0056–0058 migrations.
It collects complete typed catalog DATA, native physical metadata and source
identity. Both normalized catalogs must match, while their actual database,
owner and marker identities must differ. The full105-table source shape and
function bodies, constraints, indexes, dependencies and ACLs remain part of
the comparison. Unknown or incomplete capture refuses.

This purpose has its own identity schema, runner contract, two required cases,
six JSON artifacts and JUnit report. It cannot credit an0017 reference, a0055
reference or native55/57 storage diagnostic. The command-line purpose flags
are mutually exclusive, and the default0017 behavior is unchanged. A failed
capture is retained separately and cannot replace either accepted reference.

The dedicated workflow runs only the
`work/db0058-paper58-structural-reference` branch. It preserves the exact Git
source archive and complete result hashes. Archived verification repeats the
original source/manifest/tree and result admission before comparing the pair.
It runs no schema operation or application when reading saved artifacts.

The full current58 regression separately requires both cases in PostgreSQL
component0. Their artifacts and capture environment belong to that component;
the existing0017 pair stays in component3. Unit shards and Windows do not
substitute skipped PostgreSQL cases for these observations. Historical56/57
contracts and actor restrictions are unchanged.

The resulting pair is structural DATA. A persistent Paper startup still needs
its own source-owned catalog/lock custody, the restricted actor's complete
effective privilege checks and the original broker's durable recovery and
shutdown checks. This reference does not grant Paper startup, account
completeness, Arm, submission or release authority. The runner records
`HERMETIC_REGRESSION=NOT_RUN` for this standalone purpose; final same-source
regression and actual startup remain separate acceptance requirements.
