# Full public V2 initial numeric diagnostics

This slice replays full retained public V2 packets and captured account metadata,
recomputes and verifies raw G1V2 and the original precursor, then uses the existing
location, cost and comparison arithmetic through three private shared seams.
It does not provide G7/G10/full G1–G11 qualification, G12, post-publication recheck,
portfolio approval, native source ownership, reservation, intent or submission.
All receipts remain `admission=DENY` with execution/qualification/current-owner
flags false. Math success is recorded as `math_checks_passed` only.

Public entry points are `diagnose_full_public_location_v2` and
`diagnose_full_public_economics_v2`, with their independent verification functions.
Each accepts only raw public V2 and account packets, a fixed strategy/profile,
external source/plan/profile pins and original UTC decision/deadline. A verifier
first bounds exact native output bytes and rejects hidden flags, foreign models,
serializers, Mapping/proxy referents, Decimal subclasses and timezone callbacks;
then it recomputes the entire raw source chain and compares complete bytes.
There is no legacy quote/result cast, supplied G1, direction/entry/SL/TP/score,
caller approval flag or callback. A hash proves local consistency only.

The only profile is an explicitly synthetic fixture profile copied from existing
unit-policy source. Its projected fee10bps, slippage4bps and funding buffer2bps
are scenario inputs, not authenticated fee rates. Protection parameters are the
existing fixture's slippage1/cost10/minRR2/minStopATR1/ATRbuffer.25/minBuffer5.
No native production cost profile is registered. Actual fee source, quantity,
leverage, portfolio risk, metadata ownership and account completeness remain
unknown. A future actual fee profile requires a separate source-owner/config
scope; fixture constants cannot satisfy that acceptance item.

The fixed V2 quote profile retains ticker/mark/each receipt5s, funding return90s,
settlement guard95s and zero future tolerance. The legacy cost-policy age30 field
is retained as policy identity only; it cannot relax V2 raw freshness. Funding
cost uses the actual retained forecast rate paired with upcoming `fundingTime`.
`nextFundingTime` remains the following forecast settlement. Rate-generation and
historical first-availability times remain unknown.

Only `initial_public` Demo packets with null publication barrier enter this slice.
The original actual ask/bid and source-derived event/zone/timing/service minimum
expiry are fixed. The four base strategies can produce numeric diagnostics.
All four history strategies retain their actual precursor/history and original
failure codes; an available history intent still returns
`history_numeric_slice_not_integrated` WAIT. Sweep Stage C is not borrowed.

Economics selects its original bracket once using the unchanged general
structural selector on the raw-rebuilt original market/analysis/detection with
the fixed synthetic profile and exact captured tick. The complete original
selection audit is retained. A missing/rejected bracket stays incomplete; no
SL/TP is invented or shifted. Candidate and executable-reference costs share the
same fixed original bracket. Better execution never repairs candidate failure.
This initial diagnostic receipt cannot become a later recheck or old G12 receipt.

The old APIs retain their signatures, validators, first-failure order, result
schemas, Context100 boundaries and exact legacy policy `model_dump_json` hash.
Private seams contain the original formulas: direct spread money with CEILING
1e-20, signed adverse funding, original RR, location invalidation/drift and eight
comparison measurements. Native private audit state preserves partial evidence
on late arithmetic rejection. Comparison stages preserve original conditional
field access and None semantics. No second math engine is introduced.

Source baseline is root's preserved814 checkpoint; only the three old numeric
files and ten new files are owned. The separately approved seventh precursor
test repair is an explicit one-file overlay. Stage C/data/account/control and
other concurrent canonical changes are excluded from the frozen source.
Before runtime, root receives exact old/new source and dependency pins, an AST
expansion proof and sealed old/new byte-comparison scenarios. Source review and
Ruff do not count as behavioral or native acceptance. Root alone runs bounded
tests and keeps every original failure. No engineering completion is claimed.
